# Repository work

Read README.md, CONTRIBUTING.md and docs/PROVENANCE.md before changes.
Keep the browsable snapshot, aggregate patch and hash records consistent.
Preserve imported authorship and the pinned baseline; explicitly document
intentional publication or implementation changes.

The owner wants this work available for others to build on. Keep validated,
authorized code progress committed and pushed to this dedicated repository,
and report the public commit or branch. Do not claim that local edits have
been uploaded. Do not force-push or rewrite published checkpoint history.

Never commit firmware, private captures, credentials, personal device IDs,
boot images or generated build directories. Review the exact staged payload.
Keep hardware observations distinct from source checks, builds and mocks.
Publication does not authorize new hardware experiments or disk writes.
Run the review checks and affected tests; preserve fail-closed device guards.
